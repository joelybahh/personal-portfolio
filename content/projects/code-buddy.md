**Code Buddy** is an AI-powered developer assistant built as a command-line tool. It automates commits and other repetitive chores, designed to streamline development and take the friction out of everyday Git work.

## What I worked on

- **CLI in TypeScript** — a fast, scriptable command-line experience.
- **OpenAI integration** — generating meaningful commit messages from staged changes.
- **Config-driven** — a small config file lets each project tune behaviour to its own conventions.

A personal project born from a simple annoyance: writing good commit messages is tedious, and bad ones are worse. Code Buddy reads what actually changed and proposes a message worth keeping.
